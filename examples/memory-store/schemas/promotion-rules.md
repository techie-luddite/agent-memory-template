# Promotion Rules

## Promote to `active`

Promote when a candidate is:
- directly relevant to current work
- a recently confirmed environment or project fact
- a recently stated user preference
- a current operational focus, blocker, or dependency

## Promote to `durable`

Promote when one or more are true:
- explicitly marked important by the user
- major architectural or strategic decision
- stable environment truth
- policy or non-negotiable rule
- repeated recurrence indicates persistence
- future correctness depends on remembering it

## Suppress instead of promoting when:
- the item is stale
- the item is too noisy for default retrieval
- the item is superseded
- the item is only valid in a past scope or condition

## Do not promote

Do not promote:
- one-off chat fragments
- raw tool output
- bulky documentation
- speculative statements without confirmation
- material better suited for library
